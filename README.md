# Custom Villager Trades — Build Custom Shops for Any Villager

Custom Villager Trades 9minecraft Mod lets you change what villagers and wandering traders sell through simple text files. You can set any cost and reward for every job without writing code or datapacks. It helps you build custom shops, adjust item prices, or replace default trade offers completely.

Lets you create custom trade offers for every villager profession and the wandering trader. Accepts any item in the game for trade payments and trade rewards.

## What this build is

An unofficial rebuild of **lingyuan23333**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
